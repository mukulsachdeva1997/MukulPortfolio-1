Place your headshot here as `profile.jpg` (used by hero-section.tsx).

Project screenshots go in `projects/`, named to match each project's `id` in
`projects-section.tsx` — e.g. `projects/knowyourrights.png`, `projects/tidyteam.jpg`.
Accepted formats: png, jpg, jpeg, webp. A project with no matching file falls
back to a gradient + initials placeholder automatically — no code change needed
either way.

Interest photos go in `interests/`, named to match each interest's `id` in
interests-section.tsx — `interests/trekking.jpg`, `interests/fitness.jpg`,
`interests/sketching.jpg`. Same rule: no matching file falls back to a
gradient + icon placeholder automatically, no code change needed.
